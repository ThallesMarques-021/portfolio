# Portfólio — Thalles Marques

Site estático responsivo pronto para GitHub Pages.

## Publicar
1. Crie um repositório público chamado `portfolio` na conta `ThallesMarques-021`.
2. Extraia o conteúdo deste ZIP e envie os arquivos e a pasta `assets` para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)`, e salve.
5. Aguarde a publicação em `https://thallesmarques-021.github.io/portfolio/`.

Não é necessário apagar ou alterar os repositórios existentes.
